# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 退款针对已受理订单的已收金额；退款金额必须为正整数且不超过订单金额，否则按参数不合法处理。
- 可退金额 = 已收金额 − 已生效退款合计（待处理与已生效均占用可退额度）；超过可退金额按额度越界拒绝。
- 订单不存在或属其他租户时，退款受理一律按“不存在”处理，不泄漏对象是否存在。
- 退款单状态：待处理（pending）→ 冲正（reversed，终态）；冲正对待处理或已生效单生效并立即释放其占用额度，已冲正单重复冲正返回冲突且不改变状态。
- 冲正必须原子：状态翻转与额度释放在同一事务提交，失败不得留下部分占用或部分释放。
- 受理与冲正按（租户, 操作, 目标标识, 请求指纹）幂等：重复提交返回与首次相同的业务结果，不产生第二次受理/扣减/释放；同目标不同指纹并发只允许一个生效；重放识别持久化，服务重启后仍然有效。
- 任意受理、冲正序列后守恒：已生效退款合计 ≤ 已收金额 ≤ 订单金额。
